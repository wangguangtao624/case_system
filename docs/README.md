# 项目文档目录

本文档目录用于给维护者、二次开发者和交接同事快速建立上下文。

## 文档清单

- [项目总览与快速开始](./project-overview.md)
- [开发与部署指南](./development-guide.md)
- [鉴权与权限设计说明](./auth-permission-design.md)

## 建议阅读顺序

1. 先看 `project-overview.md`，了解项目目标、目录结构、核心模块和运行方式。
2. 再看 `development-guide.md`，熟悉本地开发、构建发布、备份恢复和常见风险。
3. 最后看 `auth-permission-design.md`，理解当前登录态、权限判定、测试者分配和问题单流程权限。

## 适用对象

- 新接手本项目的开发者
- 需要对接公司统一鉴权平台的二次开发者
- 负责部署、发布和维护的运维同事
