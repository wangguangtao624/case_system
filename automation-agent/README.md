# Windows 测试台状态代理（第一阶段）

此阶段仅将 Agent 在线状态和系统识别出的串口汇报到开发平台；不控制继电器或度信设备，不领取、执行测试任务，也不代表设备已完成验证。

管理员在用例详情的“自动化测试 → 设备工作台状态”注册工作台，将一次性显示的 JSON 保存到设备电脑上受权限保护的位置（不要提交 Git）。Windows 端准备 Python 和 `pyserial` 后，在本目录运行：

```powershell
py -m pip install pyserial
py workbench_agent.py --config C:\安全目录\workbench.json
```

无 pyserial 时仍会上报心跳，但串口列表为空；串口名称不是继电器或度信设备身份确认。每 10 秒上报一次，30 秒未收到心跳视为离线。管理员可停用令牌，停用后 Agent 不能继续上报。当前开发环境使用内网 HTTP，令牌传输未加密，仅用于受信任开发网络；团队投入使用前必须启用 HTTPS、设备鉴权及密钥轮换。

尚需完成任务队列、设备独占、断线处理、实际硬件身份识别、设备 SDK 对接、日志/图片回传以及桌面画布共享设备锁。代理不能用于真实自动化执行。
